# Elliptic-curve discrete-logarithm teaching notes

This is a static, multipage companion to the September 3, 2026 IonQ paper by Häner et al. All authored website content, scripts, styles, data, and assets are under this directory. Hosting identity is kept in the parent `.openai/hosting.json`.

The canonical lesson content is `content/*.json`. Each lesson has a slug, title, group, order, source pages, HTML body, and reference list. Mathematics uses only `\(...\)` and `\[...\]`. The local KaTeX distribution renders it to HTML and MathML at build time; no external runtime script or font service is required.

Run `python build.py` to generate `dist/`, then `python scripts/audit_site.py dist` and `node --check site.js`. The build fails on malformed TeX. The audit checks every internal page, asset, heading link, duplicate ID, image alternative, and raw math fragment. It is a static-output audit, not browser automation.

`content/*.json` is the only lesson source. Obsolete one-off authoring helpers have been removed so they cannot overwrite audited revisions. `data/runtime.json` contains the disclosed layer counts and the more precise duration from Appendix E23. The website's chart reads this JSON locally. `data/evidence-ledger.json` records source locations and claim status.

The exact-order Fourier visualization is generated by `visuals.py`; the controls in `site.js` change the coset and secret scalar. Run `node scripts/check_fourier_visual.cjs` after a build. It checks the actual event handlers and static fallback against an independently evaluated inverse DFT for every one of the 49 settings. It does not claim browser layout or keyboard testing. The complete Q66 certificate is downloadable as `data/q66-representatives.json`; the lesson shows the instructive supports instead of 190 table rows.

Source schedules remain in native HTML disclosures. Their original captions, full-size circuit images, and source links remain available. Compact semantic tables show register contents, branch corrections, and physical support; they are not image approximations of numerical results.

Source circuit figures in `assets/` are extracted from the user-supplied paper and credited in their captions; they are not original simulations. The two empirical curves whose raw data were not provided are linked to their source instead of being reconstructed from invented samples. New explanatory circuit SVGs are embedded in the lesson HTML.

Before deployment, `python scripts/materialize_website.py SOURCE NEW_DESTINATION` creates a separate copy with symlinks resolved. Build and check that copy to verify independence from the original checkout. Keep the development source and any development symlinks unchanged.

Scientific checks and reproduction limits are described in the site at `/lesson/audit/` and `/lesson/conclusion/`.
